# Label

Small, semi-bold inline label. `muted` variant for secondary labels.

**File:** `app/components/atoms/(typography)/Label.vue`
**Import:** `<Label>`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `muted` | `boolean` | `false` | Use muted color + regular weight. |

## Usage

```vue
<Label>Required</Label>
<Label muted>Optional</Label>
```

## Notes
- Renders a `<span>`. Font 0.8125rem, weight 600, slight letter-spacing.
